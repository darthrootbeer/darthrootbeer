### What I actually do

**Documentation systems.** Multi-stage pipelines where AI handles research,
drafting, and verification under direction, with review as a real gate rather than
a rubber stamp. Each stage is auditable on its own, so the process can be checked
instead of trusted.

**Information architecture.** Diátaxis restructures, content lifecycle scoring,
taxonomy work, and the unglamorous business of deciding what to delete.

**Docs for machines.** `llms.txt`, MCP servers, markdown endpoints. Developers now
point AI tools at documentation before they read it themselves, and those tools
need different things than a person skimming a page.
